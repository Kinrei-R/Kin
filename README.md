# Kin 🎵

An open-source Android application that allows friends to share and view what music they are listening to in real-time, across any music streaming app.

## Features
- Real-time music activity synchronization.
- Compatible across multiple audio/streaming apps via Notification Listener services.
- Secure Google Sign-In integration.
- Clean, modern UI built for Android.

## Tech Stack
- **Language:** Kotlin
- **UI:** Jetpack Compose
- **Architecture:** MVVM / Services
- **Backend/Auth:** Firebase & Google Sign-In
